## 🔹 領域一：高效率 AI / Edge AI（模型壓縮與邊緣部署）— 主力強項

涵蓋「剪枝 → 量化 → 知識蒸餾 → 部署」完整模型壓縮流程，是本作品集最深入、最有差異化的主題。

### 1. ResNet-50 通道剪枝與微調 (Channel Pruning)
- **亮點**：以 BatchNorm γ 之 L1 稀疏化進行通道剪枝，將 ResNet-50 參數量自 **23.5M 壓縮至 3.65M（約 -84%）**，微調後測試準確率自剪枝後的 60.3% 回復至 **91.8%（幾乎無損）**。
- **技術棧**：PyTorch、ResNet-50、Network Slimming（L1 sparsity training, λ=1e-4）、channel pruning、fine-tuning。
- **工程深度**：自行重寫 `_make_layer()` 使模型可依剪枝後 `cfg` 動態重建；以 `idx0/idx1` 遮罩精準搬移卷積/BN/Linear 權重；處理 Bottleneck 殘差維度對齊（固定 conv3 與 downsample 不剪）以避免 shape mismatch。
- **位置**：[EAI/Lab2 Material/](../EAI/Lab2%20Material/)｜PDF：[EAI_Lab2_通道剪枝_ResNet.pdf](作品集PDF/EAI_Lab2_通道剪枝_ResNet.pdf)

### 2. 模型量化 (Quantization：PTQ / QAT)
- **亮點**：對 CNN 進行 INT8 後訓練量化（PTQ）與量化感知訓練（QAT），推論延遲自 **FP32 10.62ms 降至 INT8 3.47ms（約 3.06× 加速）**，準確率維持 **95.38%**。
- **技術棧**：PyTorch Quantization、PTQ、QAT、INT8、latency benchmarking、confusion matrix 分析。
- **位置**：[EAI/Lab3 Material/](../EAI/Lab3%20Material/)

### 3. 知識蒸餾 (Knowledge Distillation)
- **亮點**：以 ResNet-50 為 Teacher、ResNet-18 為 Student 進行 offline distillation，透過 soft logits + temperature 調控，在縮小模型的同時保留精度。
- **技術棧**：PyTorch、KD loss（KL divergence + CE）、temperature scaling、teacher–student 架構。
- **位置**：[EAI/Lab4 Material/](../EAI/Lab4%20Material/)

### 4. Vision Transformer Token 剪枝 (EViT)
- **亮點**：在 ViT 的 Block 3/6/9 以注意力分數進行 token pruning（keep_rate=0.7），保留前景語意 token、丟棄背景冗餘 token；實作 `get_real_idx` 將剪枝後相對索引還原為原圖絕對位置以正確可視化。
- **技術棧**：Vision Transformer、EViT、token/attention-based pruning、可視化分析。
- **位置**：[EAI/Lab6 Material/](../EAI/Lab6%20Material/)｜PDF：[EAI_Lab6_Transformer剪枝.pdf](作品集PDF/EAI_Lab6_Transformer剪枝.pdf)

### 5. NumPy 手刻 MLP (從零實作神經網路)
- **亮點**：不依賴深度學習框架，純 NumPy 實作多層感知器（前向/反向傳播）於 MNIST 分類，理解梯度與最佳化底層原理。
- **技術棧**：NumPy、MLP、backpropagation、MNIST。
- **位置**：[EAI/Lab1 Material/](../EAI/Lab1%20Material/)

### 6. Gradio 模型部署介面
- **亮點**：以 Gradio 建立可公開存取的模型推論介面，支援跨裝置（手機/平板）上傳影像即時推論。
- **技術棧**：Gradio、模型服務化、Web demo。
- **位置**：[EAI/Lab5 Material/](../EAI/Lab5%20Material/)

### 7. 期末專題：高效率長照陪伴機器人（系統提案）
- **亮點**：設計可於 **Jetson Nano / Raspberry Pi** 離線運行的長照語音互動機器人，整合 ASR（Distil-Whisper）+ 輕量 LLM（量化 LLaMA-3-mini/Phi-3）+ CV 物件追蹤（YOLOv8-Nano），訂定延遲 ≤1.2s、總模型 ≤400MB、功耗 ≤15W 的效率目標。
- **技術棧**：Edge AI 系統設計、TensorRT/TFLite、INT8 量化、2:4 結構化剪枝、ONNX、語音/LLM/CV 多模組整合。
- **位置**：[EAI/Final_Project/](../EAI/Final_Project/)｜PDF：[EAI_期末_長照機器人提案.pdf](作品集PDF/EAI_期末_長照機器人提案.pdf)

## 🔹 領域二：電腦視覺 / 深度學習

### 9. UAV 空拍影像語意分割 (Kaggle)
- **亮點**：建立完整 UAV 16 類語意分割 pipeline，比較 DeepLabV3-ResNet50/101 與 UNet++-ResNet101；**DeepLabV3-ResNet101 取得最佳 Kaggle Public mIoU 0.5809**。針對長尾類別採用 CE+Dice 混合損失，並對 encoder/decoder 設定分組學習率。
- **技術棧**：PyTorch、DeepLabV3、UNet++（segmentation_models_pytorch）、ResNet-101、Dice/CE Hybrid Loss、CosineAnnealingLR、資料增強、mIoU、RLE 編碼。
- **量化成果**：mIoU 0.51 → 0.58；修正 pipeline（尺寸對齊/normalize 一致性）後分數自 0.26 回升至 0.58。
- **位置**：[ML/kaggle/ML_HW2/](../ML/kaggle/ML_HW2/)｜PDF：[ML_UAV語意分割.pdf](作品集PDF/ML_UAV語意分割.pdf)

### 10. 影像分類期中專題（兩主題）
- **亮點**：於「剪刀石頭布辨識」與「七類臉部表情辨識（FER, ~4.5 萬張）」兩任務上，比較 ResNet18 / EfficientNet-B0 / 自建 SimpleCNN；表情辨識 EfficientNet-B0 達 **~79.1% 驗證準確率**，並做混淆矩陣錯誤分析。
- **技術棧**：PyTorch、ResNet18、EfficientNet-B0、自定義 CNN、transfer learning、early stopping、confusion matrix。
- **位置**：[compute_vision/midtern_project/](../compute_vision/midtern_project/)｜PDF：[CV期中_影像分類.pdf](作品集PDF/CV期中_影像分類.pdf)

## 🔹 領域四：大型語言模型 / NLP

### 13. RAG 講義問答系統（RAG vs. 無 RAG 對照實驗）

- **技術棧**：Gemma-3-1B、Llama3.2/Ollama、SentenceTransformers（all-MiniLM-L6-v2）、FAISS、python-pptx、HuggingFace evaluate、BERTScore。
