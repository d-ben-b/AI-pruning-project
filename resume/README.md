# 📁 resume — 履歷整理資料夾

這個資料夾彙整了本 repo 所有課程／競賽專案中，**做履歷會用到的素材**。

## 內容

| 檔案 | 用途 |
| --- | --- |
| [履歷草稿.md](履歷草稿.md) | 可直接編輯投遞的履歷骨架，補上個人資訊即可 |
| [專案作品集.md](專案作品集.md) | 18 個專案的完整整理，含技術棧與量化成果，挑句子貼進履歷 |
| [技能總覽.md](技能總覽.md) | 依領域分類的技能清單，方便填技能欄位 |
| [作品集PDF/](作品集PDF/) | 8 份關鍵報告 PDF，可附在作品集或面試展示 |

## 建議使用流程

1. 先看 [專案作品集.md](專案作品集.md) 末尾的「亮點數據速查表」，挑出最強的成果。
2. 打開 [履歷草稿.md](履歷草稿.md)，補上 `【請填寫】` 的個人資訊。
3. 依目標職缺調整專案順序（AI/ML、Edge AI、資料科學各有對應專案）。
4. 需要附件時，從 [作品集PDF/](作品集PDF/) 取對應報告。

## 最強的差異化主題

**高效率 AI / 模型壓縮**（剪枝、量化、知識蒸餾、ViT token pruning、邊緣部署）是這套作品集最深入、最少人有的主題，建議作為履歷主軸。
